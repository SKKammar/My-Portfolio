A clean, modern, and highly responsive personal portfolio website designed to showcase my software engineering projects, technical skills, and experience. Built with performance and clean architecture in mind.

🔗 **Live Demo:** [my-portfolio-sanka.vercel.app](https://my-portfolio-sanka.vercel.app)

---

## ✨ Features

* **Modern UI/UX:** A clean, minimalist design that prioritizes readability and user experience.
* **Project Showcase:** Detailed cards for featured projects, including descriptions, tech stacks, and direct links to live demos or source code.
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.
* **Dynamic Sections:** Smooth navigation between About, Projects, Skills, and Contact sections.
* **Fast Performance:** Leverages Next.js server-side rendering and static site generation for optimal loading speeds.

## 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Language:** [TypeScript](https://www.typescriptlang.org/) for static type checking and robust code.
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) for utility-first, responsive styling.
* **Deployment:** Hosted on [Vercel](https://vercel.com/) for seamless CI/CD.
